Bot para gastos personales. 

Este bot esta creado en Python y funciona con Telegram y Google Sheets. 
a google sheets lo usa para registrar los datos y Python es el motor.

Tiene verificacion de usuarios mediante el ID de telegram para que no lo pueda utilizar cualquiera que no este autorizado. 
Tambien permite utilizar varias Sheets de google para tener bases separadas para multiusuarios.
